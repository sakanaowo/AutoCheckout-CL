## Quy trình đã chạy

```text
python -m tools.synth_v2 plan     --config configs/data/synth_v2.json --out-dir data/processed/rpc_synth_v2_v1
python -m tools.synth_v2 generate --config configs/data/synth_v2.json --out-dir data/processed/rpc_synth_v2_v1 --workers 16
python -m tools.synth_v2 export   --config configs/data/synth_v2.json --out-dir data/processed/rpc_synth_v2_v1
python -m tools.synth_v2 verify   --config configs/data/synth_v2.json --out-dir data/processed/rpc_synth_v2_v1 --rle-sample 2000
python -m tools.synth_v2 eval-set --config configs/data/synth_v2.json --out-dir data/processed/rpc_eval_official_v1
```
